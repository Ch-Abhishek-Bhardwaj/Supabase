# Supabase Practice 🚀

This repository contains my practice and experiments with **Supabase**, focusing on how to integrate it with frontend projects and use its core features like authentication, database, and APIs.

---

## 📌 What is Supabase?

Supabase is an open-source backend-as-a-service that provides:
- PostgreSQL database
- Authentication
- Real-time subscriptions
- Storage
- Auto-generated APIs

---

## 🎯 Purpose of this Repo

- Learn how to connect Supabase to a project
- Practice CRUD operations
- Implement authentication
- Understand Supabase client usage
- Build small demo features

---

## 🛠️ Tech Stack

- JavaScript / TypeScript
- Vite (Frontend setup)
- Supabase JS Client
